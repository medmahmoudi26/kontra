# run xfail(strict=True) and fails the run when an entry passes, errors or skips, when a test that is not listed
# ends xfailed (the TCK xfails SHOULD requirements itself), or when an entry names no collected test: for each
# variant and binding, the xfailed set is exactly the entries here. Format: one pytest node id per line, "#", and the
# reason, which cites an a2a-tck issue or a decision; a line "[<variant> ...]" starts the entries of those variants
# (TCK_VARIANT, scripts/tck.sh); the entries before the first section are every variant's. An entry's binding is its
# id's suffix. Delete an entry when its cause is gone (strict XPASS says so) and re-pin deliberately.
#
# Measured by M4 WP-02 on 28 Oct, the four variants each run twice (jsonrpc, then http_json), the same outcomes each
# time: direct, tunnel and caddy 75 passed and 8 xfailed (jsonrpc), 69 passed and 8 xfailed (http_json); auth 81
# passed and 3 xfailed (jsonrpc), 81 passed and 2 xfailed (http_json). The rest skip: the bindings not asked for and
# gRPC, the capability tests a gate that streams and pushes cannot trigger, and, through the gate only, the tests
# whose prerequisite task is a resend of an earlier test's (the TCK's message ids are per session, DM4-24).
#
