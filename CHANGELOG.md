## 0.1.0

The first tagged release, and the first time `.github/workflows/release.yml` has ever executed: it
triggers on `push: tags: v*` and this repository had no tags, so a release pipeline had been sitting
armed and unfired since it was written.

`0.1.0` rather than `1.0.0` deliberately. The appliance, the console login, the fleet path and the
DuckLake datasets all work, but nothing here carries a compatibility promise yet and the version
should say so rather than imply one.

What a release contains, per platform (linux and macOS, amd64 and arm64): the `kontra` binary, the
orchestrator bundle for that platform, and the browser bundle — laid out where an installed binary
already looks for them, with a `SHA256SUMS` covering all four. Each platform is built on its own
native runner and the resulting binary is unpacked and executed there before it ships.
